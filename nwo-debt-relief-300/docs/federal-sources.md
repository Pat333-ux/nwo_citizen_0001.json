# Federal Sources

Every program in `data/programs.json` must cite `source_urls` from these authorities and carry a `last_verified` date.

| Source | URL | Covers |
|---|---|---|
| StudentAid.gov | https://studentaid.gov | Student loan forgiveness, discharge, repayment |
| IRS.gov | https://www.irs.gov | Offer in Compromise, installment agreements |
| SBA.gov | https://www.sba.gov | Disaster and hardship loan relief |
| HUD.gov | https://www.hud.gov | FHA loss mitigation |
| VA.gov | https://www.va.gov | VA home loan assistance |
| USDA.gov | https://www.rd.usda.gov | Rural housing hardship |
| LIHEAP | https://acf.gov/ocs/programs/liheap | Utility assistance |
| SAM.gov Assistance Listings | https://sam.gov/content/assistance-listings | Authoritative federal assistance catalog |
