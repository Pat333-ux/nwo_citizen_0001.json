# Incident Response Plan

1. **Detect**: monitoring, alerts, user reports, ledger verification failures.
2. **Triage**: assign severity (Low / Medium / High / Critical) and an incident lead.
3. **Contain**: revoke affected tokens, suspend affected identities or services, isolate systems.
4. **Eradicate and recover**: fix the root cause, restore from backup if needed, re-verify the ledger hash chain.
5. **Notify**: follow the Breach Notification Plan where PII is involved.
6. **Review**: post-incident report within 14 days with corrective actions, recorded as an audit item.

A broken hash chain is always treated as High severity or above.
