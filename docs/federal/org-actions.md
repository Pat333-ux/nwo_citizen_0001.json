# Actions Required From the Organization

These cannot be done in this repository.

1. Register in SAM.gov (Unique Entity ID); confirm NAICS codes.
2. Choose the target agency, program and contract vehicle (GSA Schedule, set-aside, SBIR/OTA).
3. Confirm eligibility, insurance, financial and past-performance requirements.
4. Engage counsel on FAR/DFARS clauses, data rights, Privacy Act, SORN and PIA obligations.
5. Decide cloud service offering (FedRAMP) vs. on-premises (agency ATO).
6. Engage a FedRAMP advisor and a 3PAO; identify the authorizing official.
7. Select FIPS 140-3 validated cryptographic modules for production.
8. Select an identity federation approach (PIV/CAC, Login.gov, OIDC/SAML).
